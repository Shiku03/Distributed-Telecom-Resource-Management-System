# Milestone Submission Structure

This repository is subdivided into the following submission folders:

| Submission folder | Milestones | Repository state included |
|---|---|---|
| `Assignment1/` | Milestones 1 and 2 | Complete current project copy |
| `Assignment2/` | Milestones 3 and 4 | Complete current project copy |
| `Assignment3/` | Milestones 5 and 6 | Complete current project copy |
| `Practical1/` | Milestones 7 and 8 | Complete current project copy |
| `Practical2/` | Milestones 9 and 10 | Complete current project copy |

Each folder is an independent copy of the tracked project files and contains the complete final implementation. The repository root contains only this submission index and the root README; shared code and data are not stored separately at the root.

Because the repository's Git history does not contain separate snapshots for every milestone, each submission folder currently contains the complete final project rather than reconstructed milestone-only source snapshots.
